## Key Constraints (Things That Will Bite You)
- UI is in Hebrew (RTL). **Never touch Hebrew strings.**
- 4 tracks: חשמל, מחשבים, חשמל+מתמטיקה, חשמל+פיזיקה
- **Never rename** the `persist({ name: ... })` key in the Zustand store — that is the localStorage key.
- `src/data/generalRequirements/` is script-generated. Do not hand-edit it.
- `public/grade-statistics.json` is generated by `scripts/sync-grade-statistics.mjs`. Do not hand-edit it.
- Tailwind v4: no string interpolation in class names (dynamic classes won't scan).

## Codebase Graph (graphify)
- `graphify-out/graph.json` + `graphify-out/GRAPH_REPORT.md` are a committed, queryable code graph (2141 nodes / 4247 edges as of the last extraction), built locally with [graphify](https://github.com/Graphify-Labs/graphify) — AST-only, no LLM calls, no API key needed.
- Prefer this over broad grep/explore for "where is X" / "what depends on Y" questions: `graphify query "<question>" --graph graphify-out/graph.json`, `graphify explain "<Node>"`, `graphify path "A" "B"`, `graphify god-nodes` (architectural hubs).
- Requires the CLI: `uv tool install graphifyy` (one-time, not an npm dependency).
- **Stale graph**: after nontrivial code changes, run `graphify update . --code-only` to refresh `graph.json` (few seconds, local-only) before relying on query results.
- Auto-refresh on every commit/checkout is NOT installed (blocked by this environment's tool-permission policy, since it modifies repo automation). Run manually once if you want it: `graphify hook install`. There's also a deeper Claude Code integration (writes a graphify section into this file + a PreToolUse hook) via `graphify claude install` — also not installed here for the same reason; run it yourself if wanted, then review the diff.
- Community labels in the report are unnamed (`Community N`) because labeling requires an LLM backend (`graphify label . --backend=claude|gemini|openai|...`), which wasn't run to avoid unexpected API usage. Optional — run it yourself if you want named clusters.
